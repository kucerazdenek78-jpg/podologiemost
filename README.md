# Podologie Most

Prezentační web – podologie a profesionální pedikúra, Hana Follprechtová, salon Višňová, Most.

## Co doplnit
- **Video na pozadí:** nahrát soubor `assets/video/hero.mp4` (web ho sám použije, jinak běží animované slidy)
- **Fotky:** `assets/img/` (foto Hany / salonu – v `index.html` označeno komentářem `SEM PŘIJDE FOTKA`)
- **Ceník:** v `index.html` komentář `CENY DOPLNIT`
- **Přesná adresa + mapa:** sekce Kontakt, komentář `SEM PŘIJDE MAPA`

## Zveřejnění
GitHub → Settings → Pages → Source: *Deploy from a branch* → `main` / root.
